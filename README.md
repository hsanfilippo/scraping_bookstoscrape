## Tecnologias utilizadas:
- `requests`
- `bs4` (BeautifulSoup)

## Como rodar:

### 🐧 Linux:
- Navegue até o diretório do projeto em seu local de preferência;
- Crie um ambiente virtual para instalar as dependências com:
  - `python3 -m venv [nome_do_ambiente]`
- Acesse o ambiente com:
  - `source [nome_do_ambiente]/bin/activate`
- Instale as dependências:
  - `pip install -r requirements.txt`
- Execute o script:
  - `python3 main.py`

### 🪟 Windows:
- Navegue até o diretório do projeto em seu local de preferência;
- Crie um ambiente virtual para instalar as dependências com:
  - `python -m venv [nome_do_ambiente]`
- Acesse o ambiente com:
  - `.\[nome_do_ambiente]\Scripts\activate`
- Instale as dependências:
  - `pip install -r requirements.txt`
- Execute o script:
  - `python main.py`
