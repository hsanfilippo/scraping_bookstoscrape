# Scraping https://books.toscrape.com
Este repositório é apenas um estudo de scraping com Python.

## Tecnologias utilizadas:
- `requests`
- `bs4(BeautifulSoup)`

## Como rodar:
Basta instalar as dependências listadas em `requirements.txt` e executar:

- Linux: `python3 main.py`
- Windows: `python main.py`
- MacOS: Mudar para Linux ou Windows kkkkk
